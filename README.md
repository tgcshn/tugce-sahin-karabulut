# Tuğçe Şahin Karabulut – Kişisel Web Sitesi
Astro ile hazırlanmış statik web sitesi. Randevu sistemi ve veritabanı yoktur.

## Cloudflare Pages ayarları
- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/`

## Yerel çalıştırma
`npm install` ardından `npm run dev`.

## Önemli
İletişim, eğitim ve uzmanlık bilgileri doğrulanmadan yayına alınmamalıdır. Fotoğrafın kullanımı için hak sahibinin onayı alınmalıdır.
